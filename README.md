# nim-snippets — 元ファイル保管

`nim_environment_update_ver6.zip` に含まれる4ファイルを、そのままGitに保存しています。添付内の更新スクリプトは実行せず、既存のNim環境・設定・解答は変更していません。

GitHubの通常表示は、日付付きのVS Code定義とライセンスを載せる [スニペット一覧](https://github.com/springharu7c/nim-snippets/tree/public) です。この `environment` ブランチは元パッケージの保管用です。

| SNIPPETS_LICENSE | 添付のライセンス表示 |

スニペット定義のライセンスは、添付の `SNIPPETS_LICENSE` に従いCC0 1.0 Universalです。[LICENSE](LICENSE)に正式な本文を置いています。この表示により、添付の他のファイルへ新たなライセンスを付与するものではありません。

保存日は2026-10-17です。コードの作成日・利用開始日・Webでの公開日を証明するものではありません。元ZIPと各ファイルのSHA-256は [SOURCE.json](SOURCE.json) に記録しています。

今回はJSONの読み込み、55候補の構造、元ZIPとの内容一致を確認しています。Nimのコンパイルやアルゴリズムの再検証は行っていません。
